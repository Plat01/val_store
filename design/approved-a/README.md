# Этап 4 — утверждённый вариант A

Заказчик выбрал вариант A из [исходного сравнения A/B](../concepts-v1.html).
Направление: модульная главная, Manrope, выбор модели плашками с ценой и
характеристиками рядом с фото. Вариант B остаётся в исходном сравнении.

## Просмотр

Из корня проекта запустить `python3 -m http.server 8090 --bind 127.0.0.1`:

- [Главная](http://localhost:8090/design/approved-a/home.html)
- [Карточка товара](http://localhost:8090/design/approved-a/product.html)
- [UI-гайд](http://localhost:8090/design/approved-a/ui-guide.html)

HTML можно открывать и непосредственно с диска. Шрифты и изображения локальные.
`home.html` и `product.html` — самостоятельные макеты с одним H1; контент доступен
без JavaScript. JS в карточке демонстрирует выбор модели, количество, вкладки
(включая стрелки, Home/End) и сообщение о выбранном товаре. Корзина и другие
ссылки внутри макетов демонстрационные; навигация между макетами находится сверху.
Цены, наличие и количества — снимок данных дампа 2020, не актуальный прайс.
Контакты, часы и реквизиты обозначены текстом «уточняется».

## Передача в тему

Токены записаны в `site/wp-content/themes/soberi-stanok/theme.json`: палитра,
Manrope 400–800, шкала текста, контейнер 1280 px, отступы, радиусы, скос и сетка.
Локальный WOFF2 с кириллицей/латиницей и лицензия находятся в `assets/fonts/`
темы. Источник: [google/fonts, Manrope](https://github.com/google/fonts/tree/main/ofl/manrope),
лицензия SIL OFL 1.1. Шрифт подготовлен из variable TTF через fontTools, включая
кириллицу, латиницу, символ рубля, номер и математический минус.

Токены применяются из файлов темы; существующий `site/scripts/setup.sh` уже
активирует тему через WP-CLI. Ручных настроек в админке на этапе 4 нет.
`concept.css` — визуальная спецификация, а не подключённые стили магазина.
Перенос композиций в FSE/WooCommerce-шаблоны относится к этапу 5.

При подготовке A устранены внешняя загрузка шрифта, обрезание focus скосом,
выход карточек за мобильный экран и тени-рамки. В подвале использован исходный
монохромный логотип на светлом фоне. Кнопка «Подобрать комплект» показывает
вторичное действие без обещания оформления заказа в один клик.

## Проверка

Скриншоты трёх страниц при 375/768/1440 px: [screenshots/](screenshots/).
На каждой странице один H1, нет горизонтального скролла и неоткрывающихся
картинок. Проверены загрузка локального Manrope, отсутствие ошибок JS,
обновление цены/артикула/характеристик при выборе модели, количество от 1,
сообщение выбора и клавиатурное переключение вкладок.

Контраст текста/фона: графит на primary 5,74; белый на primary-dark 5,18;
primary-dark на surface 4,75; muted на surface 5,39; danger на белом 5,16;
success на белом 5,00. В CSS нет градиентов и теней, радиусы полей 0.
Disabled показан отдельно; информационные бейджи и текущие крошки не имеют
интерактивных состояний. UI-гайд содержит обычное состояние, hover, active,
focus, disabled кнопки; поля с hover/focus/disabled/ошибкой; бейджи, наличие,
карточки, крошки, пагинацию и выбор модели.

Общие проверки: `npm test` — 6/6, `npm run check:mcp` — OK,
`site/scripts/verify.sh` — 408 товаров/вариаций, 35 категорий, 162 файла;
слаги, цены и иерархия совпадают с источником.
