# собери станок — интернет-магазин комплектующих для ЧПУ

WordPress + WooCommerce, своя блочная тема. Новый сайт с чистого листа вместо старого
(`old_site/` — только источник товаров/категорий/картинок, не трогать, не в git).

## Структура
- `site/` — проект сайта (docker, тема, mu-plugins, скрипты). Детали — скилл `wp-local`.
- `logo/` — исходники логотипа (SVG).
- План работ: `/home/dima/.claude/plans/1-whimsical-oasis.md`.

## Правила
- Вёрстка/дизайн — сначала скилл `brand-style` (цвета, шрифт, скос 45°, запреты).
- SEO — скилл `seo-check`.
- Только бесплатные плагины; платный — только после обсуждения с пользователем.
- Всё, что настраивается в админке, дублировать в `site/scripts/setup*.sh` (WP-CLI),
  чтобы сайт поднимался с нуля одной командой.
- Контакты и реквизиты не хардкодить: берутся из «Данных магазина» (mu-plugin), до финала —
  заглушки.
- Общение и тексты сайта — на русском.
