# Фирменный стиль «собери станок»

Интернет-магазин комплектующих для ЧПУ для людей, которые собирают оборудование сами.
Характер: **современный геометрический минимализм с инженерным характером** — точность,
надёжность, простая самостоятельная сборка. Доступно и понятно, не «завод».

## Логотип (`logo/`)
Монограмма из двух букв «с», соединённых как детали конструктора: крупные сплошные формы,
прямые углы, скосы 45°.
- `soberi-stanok-logo-ss.svg` — основной (знак + надпись), шапка.
- `soberi-stanok-mark-ss.svg` — знак 96×96: favicon, apple-touch, заглушка фото товара.
- `*-mono-ss.svg` — графитовые: подвал, печать.
- `soberi-stanok-logo-solid.svg` — запасной, в интерфейсе не использовать.
Логотип не перекрашивать, не растягивать, не добавлять эффекты. Охранное поле ≥ высоты знака / 4.

## Цвета (slug в theme.json → значение)
| slug | hex | где |
|---|---|---|
| `primary` | `#0ABAB5` | фон главных кнопок, активные состояния, маленькие акценты, полоски, бейджи |
| `primary-dark` | `#067A76` | ссылки и бирюзовый **текст** на белом, hover/active кнопок |
| `primary-soft` | `#E6F8F7` | фон выделенных плашек, выбранный фильтр |
| `ink` | `#292D32` | текст, заголовки, иконки, тёмные кнопки |
| `muted` | `#5F656D` | второстепенный текст |
| `line` | `#E2E4E7` | рамки, разделители |
| `surface` | `#F4F5F6` | карточки, фон секций, подложка фото |
| `base` | `#FFFFFF` | фон страницы |
| `danger` / `success` | `#C9372C` / `#1E7F4F` | ошибки / «в наличии» |

**Контраст (проверено):** белый на `#0ABAB5` = 2.41:1 — ЗАПРЕЩЕНО для текста. На бирюзовых кнопках
текст **графитовый** `#292D32` (5.74:1). Бирюзовый текст — только `primary-dark` (5.18 на белом,
4.75 на `surface`). Графит на `primary-dark` (2.67) — запрещено: на тёмно-бирюзовом фоне текст белый.
Бирюза — акцент: не больше ~10% площади экрана.

## Типографика
- Шрифт: **Manrope** (кириллица, локально, woff2, variable 400–800). Альтернатива — Onest.
- Заголовки 700–800, плотный межстрочный (1.1–1.2), лёгкий отрицательный трекинг на крупных.
- Текст 400–500, 16–17px, межстрочный 1.55–1.6, длина строки ≤ 72 символа.
- Шкала (rem): 0.8125 / 0.875 / 1 / 1.125 / 1.375 / 1.75 / 2.25 / 3 (через clamp на мобильных).
- Цены и характеристики: `font-variant-numeric: tabular-nums`.

## Сетка и форма
- 12 колонок, контейнер 1280px, поля 16px (моб.) / 24–32px. Шаг отступов 8px (4 для мелочей).
- Радиусы 0–4px. **Никаких** pill-кнопок и больших скруглений.
- **Фирменный скос 45°**: срез одного угла (обычно правый верхний или левый нижний) через
  `clip-path: polygon(...)`, размер 8–16px. Только на: главных кнопках, бейджах, плашках
  категорий, акцентных блоках hero, рамке фото товара. Дозированно — не на каждом элементе.
- Карточка товара: фото на `surface`, название (2 строки max), 2–3 ключевые характеристики,
  цена, кнопка. Рамка `line` 1px, hover — рамка `ink` или бирюзовая полоса, без теней.
- Иконки: линейные, прямые углы, stroke 1.5–2px (Lucide/Tabler, inline SVG, `currentColor`).
- Фокус: явный outline 2px `primary-dark` с offset 2px.

## Запрещено
Градиенты, тени и объёмные эффекты (допустима только плоская смена рамки/фона), металлические
текстуры, шестерёнки и «заводская» декоративность, тёмные тяжёлые фоны на всю страницу,
сильные скругления, стоковые фото людей в касках, анимации ради анимаций (только короткие
transition 150–200ms на hover/focus).

## Проверка перед сдачей вёрстки
1. Скриншоты Playwright 375 / 768 / 1440 — нет горизонтального скролла.
2. Все пары текст/фон ≥ 4.5:1 (крупный текст ≥ 3:1).
3. Grep CSS на `gradient`, `box-shadow`, `border-radius` > 4px — должно быть пусто/обосновано.
