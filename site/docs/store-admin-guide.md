## Смена пароля WordPress

1. Откройте **Пользователи → Профиль**.
2. Найдите раздел управления учётной записью и кнопку установки нового пароля.
3. Задайте пароль и сохраните его в менеджере паролей.
4. Нажмите **Обновить профиль**.

Для другого пользователя: **Пользователи → Все пользователи → нужный пользователь**,
затем изменить пароль и сохранить. Новый пароль действует сразу.

Смена пароля WordPress не меняет пароль почтового ящика Mail.ru.

[Инструкция WordPress](https://wordpress.org/documentation/article/reset-your-password/).

### Если пароль забыт

Пока SMTP не подключён, восстановление через «Забыли пароль?» не доставит письмо.
Можно сбросить пароль администратора через SSH.

Подключитесь с компьютера, на котором есть выданный SSH-ключ:

```bash
ssh root@178.253.45.218
```

Затем выполните **на сервере**:

```bash
read -rsp 'Новый пароль WordPress: ' SS_NEW_PASSWORD
echo
export SS_NEW_PASSWORD
wp --allow-root --path=/var/www/soberi-stanok/public eval \
'wp_set_password(getenv("SS_NEW_PASSWORD"), 1);'
unset SS_NEW_PASSWORD
```

При вводе пароль не отображается. Команда меняет пароль текущего администратора
с ID `1`. Если состав пользователей изменится, сначала проверьте ID:

```bash
wp --allow-root --path=/var/www/soberi-stanok/public user list --fields=ID,user_login,roles
```

Блокировка за неверные попытки может продолжать действовать после сброса пароля:
дождитесь её окончания.

## Остальные пароли и доступы

| Доступ | Как менять |
|---|---|
| WordPress | Через профиль пользователя |
| Личный кабинет FirstByte | В настройках аккаунта FirstByte |
| Почтовый ящик | В настройках почтового сервиса |
| SSH | Добавить новый публичный ключ на сервер, проверить вход в отдельном соединении, затем удалить старый ключ |
| MariaDB и Redis | Через SSH согласованно изменить пароль сервиса и настройки подключения WordPress |

SSH работает только по ключу. Вход root по паролю отключён. Публичные ключи root
хранятся на сервере в `/root/.ssh/authorized_keys`; закрытый ключ остаётся на вашем
компьютере. Парольная фраза закрытого ключа и пароль WordPress — разные вещи.

Пароли MariaDB и Redis записаны на сервере в `/etc/soberi-stanok/secrets.env`.
**Редактирование этого файла само по себе пароль сервиса не меняет.**
В этом файле используются имена `DB_PASSWORD` и `REDIS_PASSWORD`; значения
должны быть корректно заключены в кавычки для Bash. Для новых служебных паролей
удобно использовать случайные шестнадцатеричные строки, создаваемые
`openssl rand -hex 32`.

Перед изменением создайте резервную копию:

```bash
systemctl start soberi-stanok-backup.service
```

После согласованного изменения значений в файле примените настройки на сервере:

```bash
bash /opt/soberi-stanok/scripts/setup-server-site.sh
bash /opt/soberi-stanok/scripts/setup-server-wordpress.sh
```

Это работы по обслуживанию сервера: возможен краткий перерыв сайта, а после
обновления ключей сессий потребуется снова войти в WordPress. Обычная смена
пароля администратора этих команд не требует.

Переменная `WP_ADMIN_PASSWORD` в файлах установки **не заменяет** смену действующего
пароля через профиль. Файлы первого переноса могут содержать прежний пароль;
если вы сменили пароль в WordPress, эти сохранённые значения не обновляются
автоматически и не являются источником действующего пароля.

### Особенности текущей темы

Тексты главного баннера, преимуществ, инструкции сборки и FAQ пока находятся
в коде темы. Обычное редактирование страницы «Главная» их не изменит.
Тексты юридических страниц формируются программно из шаблонов и данных магазина.
Для свободного редактирования этих разделов через админку нужна отдельная доработка.

Изменения товаров и обычных страниц сохраняются при штатной выкладке кода.
Гостевая версия страницы может обновиться с задержкой **до пяти минут** из-за кэша.

Плагины и программный код темы из веб-админки не устанавливаются и не редактируются:
их обслуживание выполняется через SSH и проект.

## Добавление обычного товара

1. Откройте **Товары → Добавить новый**.
2. Укажите название и подробное описание.
3. В блоке **«Данные товара»** выберите **«Простой товар»**.
4. Заполните цену. При необходимости укажите цену распродажи.
5. Во вкладке **«Запасы»** задайте уникальный артикул, наличие и количество.
6. Во вкладке **«Доставка»** укажите вес и размеры: используются кг и см.
7. Во вкладке **«Атрибуты»** добавьте характеристики и включите отображение
   на странице товара.
8. Выберите категорию, основную фотографию и дополнительные изображения галереи.
9. Заполните краткое описание.
10. Проверьте через предварительный просмотр и нажмите **«Опубликовать»**.

Для характеристик, которые должны работать в фильтрах каталога, используйте
общие атрибуты из **«Товары → Атрибуты»**.

Для похожего товара удобно открыть список товаров и нажать **«Дублировать»** под
существующим. Затем заменить название, артикул, фотографии, цену и остаток.

[Документация WooCommerce](https://woocommerce.com/document/managing-products/).

## Товар с вариантами

Например, один драйвер с несколькими моделями:

1. Выберите тип **«Вариативный товар»**.
2. Добавьте атрибут «Модель» и его значения.
3. Отметьте **«Используется для вариаций»** и сохраните атрибуты.
4. Во вкладке **«Вариации»** создайте варианты.
5. Для каждого варианта задайте цену, артикул, наличие и при необходимости свою
   фотографию.
6. Сохраните изменения и опубликуйте товар.

Каждому продаваемому варианту нужна цена.

[Инструкция по вариативным товарам](https://woocommerce.com/document/variable-product/).

## Изменение существующих товаров

Откройте **Товары → Все товары → нужный товар**, измените поля и нажмите
**«Обновить»**.

При редактировании существующих товаров сохраняйте адреса и категории:
от них зависят ссылки каталога и настроенные перенаправления.
Изменение URL или основной категории нужно сопровождать проверкой ссылок
и при необходимости настройкой 301-перенаправления.
